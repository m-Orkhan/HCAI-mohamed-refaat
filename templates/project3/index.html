Active Learning for Learning-to-Defer

This project builds a human-AI team for news classification on the AG News dataset. A TF-IDF + logistic regression classifier (91.89% test accuracy) collaborates with a simulated expert. A learning to defer system routes each article to whichever agent is more reliable, surpassing both individually.
